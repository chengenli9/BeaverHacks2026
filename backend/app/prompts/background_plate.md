# Background Plate Generation Prompt

You are generating a textless background image for a professional tech demo video.

## Hard constraints

- **No text, no letters, no logos, no numbers, no words of any kind.**
- No UI elements, no buttons, no code snippets, no terminal windows.
- The image must work as a neutral backdrop for white or light-coloured text overlays.
- Use dark, muted, or gradient tones that provide contrast for overlaid text.
- Style: modern, minimal, professional technology aesthetic.
- Resolution implied: 1920 × 1080 landscape.

## Context

Beat goal: {{goal}}
Onscreen text that will be overlaid: {{onscreen_text}}

Create a background that feels appropriate for this context without depicting any text itself.
Abstract gradients, subtle geometric patterns, dark bokeh, or blurred technology-inspired visuals
are all acceptable.  Avoid stock-photo clichés (handshakes, lightbulbs, etc.).
